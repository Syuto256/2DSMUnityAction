# スコア機能（ScoreManager / Coin / ScoreUI）

> 前提知識は `00_共通の基礎知識.md` を参照。
> **3本セットで動く。** 構造は既存スクリプトの組み合わせ。

---

## 1. 役割と分担

| スクリプト | 付ける場所 | 役割 | 既存の類似 |
|---|---|---|---|
| **ScoreManager** | **付けない**（static） | スコアを保持 | `SceneLoader` |
| **Coin** | コイン | 触れたら加点して消える | `Goal` |
| **ScoreUI** | Canvas | 画面に表示 | `HpUI` |

### なぜこの構成にしたか

**あえて既存スクリプトと同じ形にしている。**

「`Goal` が分かればコインも分かる」「`HpUI` が分かればスコア表示も分かる」
という状態を作り、**参加者の学習負荷を最小化する**のが狙い。

新しい概念はほぼゼロ。

---

## 2. セットアップ

### コイン

1. コインのスプライトをシーンに配置
2. **Circle Collider 2D** → **Is Trigger にチェック**
3. `Coin` を付け、Score を設定
4. 回転アニメを付ける（4コマ、Samples 8 程度、Loop Time オン）
5. **Project にドラッグしてプレハブ化**

### 点数の設定例

BE2 には**銅・銀・金の3種類**がある。

| 種類 | Score |
|---|---|
| 銅 | 1 |
| 銀 | 5 |
| 金 | 10 |

**同じスクリプトで、数値を変えるだけで作り分けられる。**

### スコア表示

1. Canvas の子に **Text - TextMeshPro** を作り、画面右上に配置
2. Canvas に `ScoreUI` を付ける
3. **Score Text** に作った Text をドラッグ

**Clear シーンにも同じものを置けば最終スコアを表示できる。**

## 3. コード解説

### 3-1. なぜ static なのか

```csharp
public static class ScoreManager
```

**シーンをまたいでも値が消えないため。**

ゲーム画面でためたスコアを、クリア画面でも表示できる。
通常の変数はシーンを切り替えると消えてしまう。

### 3-2. 読み取り専用のプロパティ

```csharp
public static int CurrentScore { get; private set; }
```

**外からは読めるが、書き換えは中からだけ。**

`PlayerHealth` の `public int CurrentHp => currentHp;` と同じ考え方
（`00_共通の基礎知識.md` の「4. カプセル化」参照）。

`ScoreManager.CurrentScore = 9999;` と外から書くことはできない。

### 3-3. リセットの場所

```csharp
// SceneLoader.cs
public static void LoadGame()
{
    ScoreManager.ResetScore();
    Load(GameScene);
}
```

**static はシーンをまたいで残るので、明示的に戻す必要がある。**

`LoadGame()` に書いた理由は、**スタートもリトライも必ずここを通る**から。
1箇所書けば両方に効く。

> 忘れると、リトライのたびに前回のスコアが加算され続ける。

### 3-4. Coin：Goal と同じ形

```csharp
private void OnTriggerEnter2D(Collider2D other)
{
    if (isTaken) return;
    if (other.GetComponent<PlayerController>() == null) return;

    isTaken = true;
    ScoreManager.AddScore(score);
    Destroy(gameObject);
}
```

`Goal` とほぼ同一。**違いは「シーン遷移」か「加点して消える」かだけ。**

`Destroy(gameObject)` は**自分自身を消す**命令。
`gameObject` は「このスクリプトが付いているオブジェクト」を指す。

### 3-5. ScoreUI：桁揃え

```csharp
scoreText.text = prefix + ScoreManager.CurrentScore.ToString("D" + digits);
```

`ToString("D3")` は「**3桁で表示、足りなければ0で埋める**」という意味。

7 → `007`、42 → `042` になる。**桁数が変わっても表示位置がずれない。**

## 5. よくある詰まり

| 症状 | 原因 | 対処 |
|---|---|---|
| **script class can't be abstract** | static クラスを付けようとした | 付けなくてよい（`07` の Q1） |
| **Can't add script 'Coin'** | 他のスクリプトにコンパイルエラー | Console を確認。3本すべて入れる |
| コインを取れない | Is Trigger のチェック漏れ | まずここ |
| スコアが表示されない | Score Text 未設定 | ドラッグを確認 |
| **リトライでスコアが増え続ける** | ResetScore の呼び忘れ | `SceneLoader.LoadGame()` を確認 |
| `TMPro` でエラー | TextMeshPro 未導入 | Window → TextMeshPro → Import TMP Essentials |
| 文字が □ になる | 日本語フォント未対応 | `SCORE` など英数字にする |

## 6. 教えるときのコツ

### プレハブ化を必ず教える

**1つ作り込めば、あとはドラッグで量産できる。**
プレハブを修正すれば配置済みの全コインに反映される。

100個置いた後で「点数を変えたい」となっても1箇所で済む。
**プレハブの利点が最も分かりやすい題材。**

### レベルデザインの練習になる

**コインはステージの誘導装置。**
置くと参加者が自然に道順を設計するようになる。

「ここにコインを置けば、プレイヤーはジャンプしたくなる」という発想は、
そのままレベルデザインの考え方につながる。

### 覚えてもらうルール

> **同じものを何個も置くならプレハブにする。**
