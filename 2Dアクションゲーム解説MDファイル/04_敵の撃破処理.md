# 敵の撃破処理（EnemyHealth / EnemyAttack / StompZone）

> 前提知識は `00_共通の基礎知識.md` を参照。
> **この3本は連携して動くため、まとめて理解すること。**

---

## 1. 役割と分担

| スクリプト | 付ける場所 | 役割 |
|---|---|---|
| **EnemyHealth** | Enemy | HPと撃破処理 |
| **EnemyAttack** | Enemy | 触れたプレイヤーにダメージ |
| **StompZone** | **Enemy の子** | 踏まれた判定 |

### なぜ3つに分けたか

**役割がはっきり違うため。**

- 「倒される」と「攻撃する」は別のこと
- **StompZone は子オブジェクトに付ける必要がある**ので、物理的に分けざるを得ない

1つにまとめると、当たり判定の場所が分からなくなる。

---

## 2. セットアップ

### Enemy 本体

EnemyPatrol に加えて **EnemyHealth** と **EnemyAttack** を付ける。

| 項目 | 値 |
|---|---|
| Max Hp | 1（一回踏むと倒せる） |
| Destroy Delay | 0.5 |
| Attack Power | 1 |

### 子オブジェクト StompZone

1. Enemy を右クリック → Create Empty、名前を `StompZone` に
2. **Box Collider 2D** を追加し、**Is Trigger にチェック**
3. **敵の頭の上、体のコライダーより少し上へはみ出す位置**に置く
4. `StompZone` スクリプトを付ける

> **はみ出させないと、踏む前に体に当たってダメージを受ける。**
> ここが最大の設定ポイント。

## 3. 連携の流れ

### 踏んだとき

```
プレイヤーが StompZone に入る
   ↓
StompZone が「落下中か」を確認   ← 下から突き上げても倒れないように
   ↓
EnemyHealth.TakeDamage(1)  → 敵が倒れる
PlayerController.Bounce()  → プレイヤーが跳ねる
```

**1つのイベントから2つの結果が生まれる。** 全体像の図で矢印が2本出ている理由。

### 横から当たったとき

```
プレイヤーが敵の体に触れる（OnCollisionStay2D）
   ↓
EnemyAttack が「敵は死んでいないか」を確認
   ↓
PlayerHealth.TakeDamage(1)
```

## 4. コード解説

### 4-1. StompZone：親を探す

```csharp
enemyHealth = GetComponentInParent<EnemyHealth>();
```

`GetComponent` は**同じオブジェクト**を探すが、
`GetComponentInParent` は**親までさかのぼって探す。**

StompZone は子オブジェクトなので、EnemyHealth は親にある。

### 4-2. StompZone：落下中かの判定

```csharp
if (playerRb.linearVelocity.y > 0f)
{
    return;   // 上に向かっている＝下から当たった → 踏んだ扱いにしない
}
```

これがないと、**ジャンプで敵の下から突き上げても倒せてしまう。**

### 4-3. EnemyHealth：倒れたら当たり判定を全部切る

```csharp
Collider2D[] colliders = GetComponentsInChildren<Collider2D>();
foreach (Collider2D col in colliders)
{
    col.enabled = false;
}
```

**これをしないと、倒した瞬間にプレイヤーがダメージを受ける。**

`GetComponentsInChildren`（複数形）は、**子も含めて全部**取ってくる。
StompZone の分も一緒に切れる。

`foreach` は「配列の中身を1つずつ取り出して繰り返す」書き方。

### 4-4. EnemyAttack：なぜ Stay を使うのか

```csharp
private void OnCollisionStay2D(Collision2D collision)
```

| | 動き |
|---|---|
| `Enter` | 触れた瞬間だけ |
| **`Stay`** | **触れている間ずっと** |

`Enter` だと、**敵に張り付いたまま無傷**になる。
`Stay` なら無敵時間が切れた後、まだ密着していれば再度ダメージが入る。

### 4-5. 二重処理の防止

```csharp
if (enemyHealth != null && enemyHealth.IsDead) return;
```

倒された敵は攻撃してこない。
**コライダーを切る処理と合わせて、二重に守っている。**

## 6. よくある詰まり

| 症状 | 原因 | 対処 |
|---|---|---|
| **踏んだのにダメージを受ける** | **StompZone が体より上に出ていない** | 位置とサイズを調整 |
| 踏んでも倒せない | Is Trigger のチェック漏れ | StompZone のコライダーを確認 |
| 下から当たっても倒せる | Require Falling が外れている | チェックを入れる |
| 敵に触れてもダメージなし | EnemyAttack の付け忘れ | Enemy 本体に付ける |
| 倒した敵が落ちていく | — | `Die()` で Kinematic にしている（正常） |
| `StompZone の親に EnemyHealth がありません` | 親子関係が違う | StompZone を Enemy の子にする |

## 7. 教えるときのコツ

### 実演すると効果的なもの

**① StompZone の位置を動かす**

Scene ビューで StompZone を体の中に埋めると、踏んでもダメージを受けるようになる。
**「当たり判定の位置が全て」**だと体感できる。

**② Require Falling を外す**

下から突き上げても倒せるようになる。**判定の意味が分かる。**

### 言い換えのストック

| 概念 | 言い換え |
|---|---|
| StompZone | 敵の頭に置いた「踏まれたセンサー」 |
| `GetComponentInParent` | 親までさかのぼって探す |
| Enter と Stay | 触れた瞬間だけ／触れている間ずっと |

### 覚えてもらうルール

> **当たり判定は「見えるもの」。Scene ビューで緑の枠を見れば分かる。**
