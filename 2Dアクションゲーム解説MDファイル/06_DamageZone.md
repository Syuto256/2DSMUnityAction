## 1. 役割

触れるとダメージを受ける場所。**2つの用途を1つのスクリプトで兼ねる。**

| 用途 | Instant Death | Damage |
|---|---|---|
| **穴（落下death）** | **チェックする** | — |
| **針・トゲ** | **チェックを外す** | 1 |

### なぜ1つにまとめたか

処理がほぼ同じで、**違いは「即死か、HPを減らすか」だけ。**
スクリプトを2つに分けると、参加者が「どっちを使うんだっけ」と迷う。

**チェックボックス1つで切り替わる方が分かりやすい。**
（`00_共通の基礎知識.md` の「7. 設計の指針」の実例）

## 2. セットアップ

### 穴（落下death）として使う

1. 空オブジェクト `DeathZone` を作る
2. **Box Collider 2D** → **Is Trigger にチェック**
3. ステージの一番下、**プレイヤーが確実に届かない深さ**に配置
4. **Size の X をステージ全体より広く**（例：100）
5. **Instant Death にチェック**

> **横幅は必ずステージより広く。** 端に隙間があると永遠に落下し続ける。

### 針・トゲとして使う

1. BE2 の `Objects.png` からトゲのスプライトを配置
2. **Box Collider 2D** → **Is Trigger にチェック**
3. **Instant Death のチェックを外す** / Damage を 1 に
4. **プレハブ化**して量産

> **当たり判定は絵より小さめに。** 先端付近だけに絞ると理不尽さが減る。

## 3. コード解説

```csharp
if (instantDeath)
{
    playerHealth.InstantDeath();
}
else
{
    playerHealth.TakeDamage(damage);
}
```

呼び分けているだけ。`PlayerHealth` 側の2つの入り口に対応している。

### Enter と Stay の設計判断

現在は **`OnTriggerEnter2D`（触れた瞬間だけ）**。

**針の上に立ち続けても、ダメージは1回きり。**
無敵が切れても、いったん離れて再度触れないと2回目は入らない。

連続ダメージにしたい場合は1行変えるだけ。

```csharp
private void OnTriggerStay2D(Collider2D other)   // Enter → Stay
```

| | Enter（現状） | Stay |
|---|---|---|
| 針の上に立つ | 1回だけ | HPが尽きるまで減り続ける |
| 難易度 | 優しい | 厳しい |
| 初心者向けか | ⭕ | △ |

**今回は Enter を推奨。** 針から脱出できずHP3が一瞬で溶けると、
参加者が「壊れている」と感じる。

## 5. よくある詰まり

| 症状 | 原因 | 対処 |
|---|---|---|
| **触れても何も起きない** | Is Trigger のチェック漏れ | まずここ |
| **落ちても死なない** | DeathZone の横幅が足りない | ステージ全体より広く |
| DeathZone をすり抜ける | 落下が速い | Collision Detection を Continuous / Y を厚く |
| 針をかすめただけでダメージ | 判定が絵より大きい | コライダーを小さく |
| 即死してしまう（針のつもり） | Instant Death が入ったまま | チェックを外す |

## 6. 教えるときのコツ

**チェックボックス1つで挙動が変わる**ことを見せると、
`[SerializeField]` の意義が伝わる。

> **「同じスクリプトでも、設定次第で穴にもトゲにもなる」**

### 注意点

**針の配置しすぎに注意。** 難易度が跳ね上がる。
作った本人はテストで慣れているので簡単に感じるが、初見の人には厳しい。
